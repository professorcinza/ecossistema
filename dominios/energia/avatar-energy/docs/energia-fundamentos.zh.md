# 基础：能源

**Avatar-Energy · 基础文档 01 · 2026年8月22日**

## 定义

**能源**是标量物理量，度量系统**做功的能力——即产生变革的能力**。三重属性定义它：

1. **守恒**（热力学第一定律）：能源不生不灭，只转化；每次转化都有一部分退化为不可用热（熵，第二定律）；
2. **可转化**：任何形式原则上可转为另一形式。SI 单位：焦耳（J）；
3. **质能等价**：E = mc²——质量即能源。

**词源**：希腊语 *enérgeia*（ἐνέργεια），出自亚里士多德——"活动，进行中的功"（*en* "在……中" + *érgon* "功"）。原义：**处于做功状态**。

## 物理形式

| 形式 | 是什么 | 例 |
|---|---|---|
| 动能 | 运动的能源 | 风、子弹、河流 |
| 重力势能 | 引力场中的位置 | 水库之水 |
| 弹性势能 | 形变 | 弹簧、弓 |
| 机械能 | 系统动能 + 势能 | 单摆 |
| 热能 | 粒子骚动 | 火、蒸汽 |
| 电能 | 电荷流动/电位 | 电流、闪电 |
| 磁能 | 磁场 | 磁铁、线圈 |
| 辐射（电磁） | 电磁波（光、射频、X、伽马） | 太阳、Wi-Fi |
| 化学能 | 分子键 | 燃料、电池 |
| 核能 | 原子核结合 | 裂变、聚变 |
| 声能 | 介质中的机械波 | 声、超声 |
| 质量 | 质能等价 | 湮灭 |
| 暗能量 | 假想的宇宙学组分（约占宇宙 68%） | 加速膨胀 |

## 当前能源矩阵来源

**非可再生**：煤 · 石油及制品 · 天然气 · 核裂变（铀；钍在研）。

**可再生**：水电 · 风电（陆/海） · 太阳能（光伏与光热） · 生物质（薪柴、乙醇、生物柴油、沼气） · 地热 · 潮汐 · 波浪 · 盐差（蓝色能源）。

**载体**（储存/运输，非来源）：氢（绿/粉/蓝） · 电池 · 压缩空气 · 飞轮。

**前沿**：核聚变（NIF 点火 2022；ITER） · 规模化绿氢 · 空间太阳能（SSP） · 环境能量采集（振动、余热、射频）。

## 物理之外的概念用法

- **生物**：ATP、代谢、营养级联；
- **信息**：兰道尔原理（擦除 1 比特耗散 ≥ kT·ln2）；
- **社会/经济**：人力/畜力；行动能力的隐喻——在物理之外，属另一种性质。

**巴西注**：大型经济体中最可再生的矩阵之一——水电为主、风电扩张、甘蔗生物质、前寒武盐下油为化石对照。
