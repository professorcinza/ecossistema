# Governance and meta: GOV, i18n, FMT

**Avatar-Energy · Base document 24 · August 22, 2026**

*The backlog's final round: the institution that outlives people, the bridge's languages, and the format that validates specs in the pipeline.*

---

## GOV — the foundation

| ID | Requirement |
|---|---|
| GOV-001 | **nonprofit, neutral foundation** (SYS-006): mission of maintaining the TeiaOS canonical tree, the specifications, and the MOD standard — no corporate ownership possible |
| GOV-002 | **government that outlives people**: elected council with limited terms (Debian heritage) + base 12's technical arbiter; succession defined before needed |
| GOV-003 | **funding without power**: public donations and sponsorships, no seat in decisions — **money doesn't buy specs**; open financial reports |
| GOV-004 | **trademarks in trust**: Teia Phone, TeiaOS, MOD and sisters belong to the foundation, in custody for the community — free use under the licenses, appropriation impossible |
| GOV-005 | **declared conflicts of interest**: public corporate ties; interested-party votes limited — capture mitigated by structure, not trust |
| GOV-006 | **radical transparency**: public minutes, decisions with recorded reason — law FIL-005 applied to governance itself; the documented graveyard lives here too |

## i18n — the bridge's languages

| ID | Requirement |
|---|---|
| I18N-001 | **PT · EN · ZH minimum** across all system interface, ecosystem documentation, and messages — the bridge speaks three languages by foundation |
| I18N-002 | **translation is a first-class contribution**: enters through the FIL sieve like any feature, with credit — and the language-coverage report is public |
| I18N-003 | **fonts and forms**: complete typographic support for all three writing systems in the base system (CJK font stack included) — translation without broken glyphs is a requirement, not a detail |

## FMT — the spec-repo format (the pipeline's grammar)

| ID | Requirement |
|---|---|
| FMT-001 | **every spec repository**: markdown with unique domain IDs, status table, CHANGELOG — the house's sheet as universal format |
| FMT-002 | **the pipeline's lint validates**: unique, domain-standard IDs; status within the `draft→reviewed→verified` cycle; **declared verification criterion** (law 2); cross-references that resolve (MOD↔TOS↔APU cannot point into the void) |
| FMT-003 | **the format is a spec too**: versioned schema in the hub — the grammar changes by commit, like everything |
| FMT-004 | the hardware module sheet (`docs/hardware/METODO.md`) is a particular case of the format — one standard, all domains |
| FMT-005 | **stable anchors**: every spec referencable by permanent identifier (MOD-015, TOS-024…) — citations that don't break with rewrites |

## The closing reading

With GOV, the ecosystem gains what none of its products has: **structural immortality** — trademarks in custody, money without power, defined succession, decisions with public reason. With i18n, the bridge speaks its name in three languages. And with FMT, the pipeline gains grammar: **specs the machine validates, humans review, and history eternalizes**.

The complete circle: an empty folder became a foundation, the foundation became specification, and the specification knows how to validate itself. **The web that weaves itself — now with bylaws.**
