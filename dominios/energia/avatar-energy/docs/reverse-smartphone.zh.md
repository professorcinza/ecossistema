# 逆向工程：高性价比智能手机（2026 年 8 月）

**Avatar-Energy · 基础文档 06 · 2026年8月22日**

---

## 制品

**Moto G Power（2026）**——公认最佳预算机：299 美元、5,200 mAh（**20 Wh**）、Dimensity 6300（**6 nm**）、30 W 充电、6.8 英寸 120 Hz、实际使用约 2 天。

## 储能规格

**化学体系**：常规石墨锂聚合物——该价位的标准（~650–700 Wh/L、~180–200 Wh/kg）。**核心发现**：2026 年的性价比冠军**不用尖端储能**（硅碳仍属高端）。胜利是**系统级的**：大常规电池 + 守纪律的软件管理。

## 功率预算（工程估算）

| 状态 | 功率 | 注 |
|---|---|---|
| 深睡（doze） | 10–30 mW | "使用中"手机的默认态 |
| 联网待机 | 50–150 mW | 射频监听 |
| 亮屏典型使用 | 600–900 mW | 屏 + 中等 SoC |
| 峰值（游戏/5G/相机） | 3–6 W | 短促爆发 |

**以实测复核**：20 Wh ÷ 2 天 ≈ **10 Wh/天 ≈ 平均连续 420 mW**——一座信息、光与通信的个人文明，运行于**不足半瓦**。

## 链条（基础 04 应用）

```
插座 → 30 W 充电器 → 电池（20 Wh）→ PMIC → 供电轨 → SoC/屏/射频 → 有效功
```

充电效率 ~85–90%（0→100% 约 70–90 分钟，CC-CV）；放电（PMIC + 轨）~90%；乘法律在每支箭上收税。

## 设备内的七项操作

| 操作 | 所居之处 |
|---|---|
| 增效 | SoC DVFS（6 nm）：每瓦最大性能 |
| 重定向 | PMIC 按需在轨间调度电压 |
| 分配 | big.LITTLE 调度；唤醒锁优先级 |
| 节约 | Doze、应用待机、调光、60 Hz 模式 |
| 储存 | 5,200 mAh 锂聚 |
| 配送 | 通往各子系统的供电轨网络 |
| 减少浪费 | 后台进程挂起 |

**管理**层（基础 03 第 5 层）即安卓自身的电源管理——**微缩的代理**：不搬能源，只决定其余一切。

## 储能经济学——主要洞见

全寿命：600–800 循环至 80% → ~20 Wh × 650 × 0.9 ≈ 一生交付 **11.7 kWh**。

- 一生*电费*：**约 1–2 美元**；
- *储能*（电池）成本：**约 40–60 美元**。

**结论**：移动设备中，能源几乎免费——**成本尽在储存与管理**。故冠军以常规化学 + 大电池 + 软件纪律取胜——而非奇异化学。

方法在两端皆成立：两种尺度下，**管理层即胜负之地**。
