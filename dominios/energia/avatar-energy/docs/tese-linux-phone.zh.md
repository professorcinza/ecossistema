# Teia Phone 论题

**Avatar-Energy · 基础文档 11 · 2026年8月22日**

*架构师论题：安卓将被 Linux Phone 取代，因 RISC-V 原生运行 Linux。*

**架构师决定（2026-08-22）**：*智能手机的操作系统发行版将由社区制作。* 项目定义硬件并公开规格；**不选择、不追随、不背书任何发行版**——彻底技术栈不可知论。以下为技术分析，非方向。

---

## 技术纠偏

**安卓即 Linux**：自 2008 年起运行于 Linux 内核。"RISC-V 原生运行 Linux"不能区分安卓与 Linux Phone——两者同坐一核。且安卓已运行于 RISC-V：DAMO/阿里巴巴，2026 年 5 月，谷歌视 RISC-V 为一等架构。

真正的分野在**用户态**：AOSP+Bionic+HAL+谷歌服务（安卓）对 GNU/glibc+GNOME/Phosh/Plasma（Linux Phone）。战争不在内核——在技术栈。

## 论题中为真的部分

1. **向主线会聚真实且不可免**：GKI 使安卓趋近主线内核；postmarketOS 已在数百机型启动主线——基础 07 "通用系统"之最纯形态；
2. **RISC-V 是历史之窗**：架构更替重塑技术栈——软件无二进制包袱时便重组。移动 ARM 之跃已然（Windows 败、iOS/安卓世界生）。RISC-V 之跃是下一次机会——Linux Phone 与安卓同等入场，无历史包袱。此况自 2008 年以来未有过；
3. **纯净技术栈更轻**：无专有服务层常驻后台，待机功耗下降（每次遥测唤醒即点亮射频——基础 06 的 420 mW 均值中所付之毫瓦）。

## 阻碍全面替代者

| 阻碍 | 状态 |
|---|---|
| 应用生态 | 数百万安卓应用 ≠ Linux 应用；桥已有（Waydroid 在 GNU/Linux 容器中跑安卓）但不隐形 |
| 封闭驱动 | 同基础 10 的调制解调器/相机——纯 Linux Phone 先于安卓受苦 |
| 经济层 | 谷歌服务是安卓的生意；移除是换经济，非仅换软件 |
| 惯性 | 用户、运营商、厂商 |

## 可能之路（标注为预测）

**分层混合**：共同主线内核 → GNU/Linux 用户态（Phosh/Plasma）→ **容器中的安卓应用**（Waydroid）承担生态。或功能反之：去谷歌化 AOSP（LineageOS//e/OS）作为"伪装的 Linux Phone"——对用户语义等价，结构上已然通用。

对 MOD 模型（基础 09）：RISC-V 算力模块 + 主线内核 + 容器安卓兼容 = **MOD-004 v2**——插槽今对 ISA **与技术栈**皆不可知。

## 能耗读法

| 因素 | 效果 |
|---|---|
| 通用主线内核 | 设备长寿命——基础 07 的 ~10:1 胜 |
| 无专有遥测之栈 | 更少射频唤醒 → 更低待机 |
| 兼容容器 | 开销小，用户可控（需时方开） |
| 今日 RISC-V | 每瓦性能仍逊最佳 ARM——诚实：效率随世代而至（RVA23 → Gen 4） |

**综合**：架构师论题中的目标（统一）为真，机制（非替代——乃**分层会聚**）需修正。内核已归一；用户态犹争；实际赢家将是交付"应用 + 长寿 + 轻盈"者——双方正会聚于此。
