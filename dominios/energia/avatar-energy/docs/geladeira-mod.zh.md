# MOD 冰箱：模块化保鲜

**Avatar-Energy · 基础 33 · 2026年8月22日**

*MOD 系列第二产品。冰箱是唯一永不关机的家电——24 小时、365 天、数十年。这是"节约"操作成为字面之处，也是工业浪费（基础 26）盘踞于每个厨房之地。*

---

## 模型：箱即家，心轮换

```
[隔热外壳 — 15–20 年]
  ├── 压缩机模块（8–10 年）  — 轮换之心
  ├── 电子模块（5 年）       — 老化之脑
  ├── 门 + 密封条（5–8 年）  — 磨损之衣
  └── 隔板/抽屉（15+ 年）    — 不动之件
```

## 代理之读

MOD 冰箱是**节约操作之化身**：在同一身体中节约食物、能源与金钱。与生态系统的结构连接超越硬件：

- 优化压缩机的**代理**即 Teia Phone 的同一 AVA-001..018，轻量配置；
- **连接**用同一协议与同一隐私纪律（本地数据、遥测须选入）；
- **200 kWh/年**为一半廉价机——每户每十年仅冰箱即省 1.4 MWh；
- **自我认证的模块化压缩机**复制调制解调器之王牌（SEG-001）：需认证技师之件轮换而外壳免重审。

**点名之敌**：一体化"智能冰箱"——贵、5 年即孤儿固件、压缩机尚好即整机报废。MOD 冰箱分离长寿者（箱）、老化者（脑）与磨损者（心）——各按己速轮换。
