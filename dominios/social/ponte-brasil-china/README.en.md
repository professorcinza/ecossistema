## About the project

This project is dedicated to building lasting bridges of friendship, understanding, and mutual benefit between the peoples of Brazil and China. We believe that relationships built on **common agreement**, **transparency**, and **mutual respect** create lasting value for both sides.

The project begins as a **unilateral commitment** — not a negotiation — assumed by a single person, holding no power of representation, in pursuit of a bilateral situation of cooperation founded on mutual support.

## Principles

1. **Common agreement** — every collaboration arises from the free and informed consent of all parties.
2. **Mutual benefit** — no proposal is good if it benefits only one side.
3. **Transparency** — the contents of this repository are public and open.
4. **Respect for the law** — respect for Brazilian law, Chinese law, and applicable international treaties.
5. **Non-officiality** — this is a citizen's project, with no governmental ties whatsoever.
