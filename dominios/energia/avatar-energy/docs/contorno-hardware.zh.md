# 硬件边界：天线、热、台架与法规

**Avatar-Energy · 基础文档 22 · 2026年8月22日**

*四个 MOD 边界领域一次成规格——设备的物理周界。*

---

## ANT——天线

| ID | 需求 |
|---|---|
| ANT-001 | **天线属于外壳**，永不属于模块——换模块绝不损失信号 |
| ANT-002 | **金属坞之难题以规格解之**：扣入金属笔记本外壳不得杀死 WiFi/BT/GPS/蜂窝——坞载天线窗**或自任辐射**（以自身天线经插槽馈模块调制解调器）——坞即广播站 |
| ANT-003 | 调制解调器（EXC-001）频段由随外壳发布的天线设计覆盖（MOD-014 开放） |
| ANT-004 | GPS/WiFi/BT/蜂窝共存于台架（RIG）验证——灵敏度劣化即规格失败 |
| ANT-005 | **每射频物理断连开关**（WiFi/BT/蜂窝/GPS），PinePhone 血统——以指为凭的隐私，非以诺 |
| ANT-006 | NFC：可选 P2，硬件可断——支付非核心需求 |

## FRI——热

| ID | 需求 |
|---|---|
| FRI-001 | **手机：百分百被动**——无风扇；算力模块 envelope（目标：持续 ≤ 5 W）经外壳散出 |
| FRI-002 | **坞：热预算属坞**——每 APU envelope 于外壳设计 |
| FRI-003 | **任意可触表面 ≤ 43 °C**（IEC 62368）——峰值、台架、35 °C 环境下 |
| FRI-004 | 模块↔外壳经插槽标准化导热垫耦合——热与数据同门而过 |

## RIG——验证台架

| ID | 需求 |
|---|---|
| RIG-001 | 基准仪器：±0.5% 级功率计（精于 AVA-002 所诺 ±1–2%——法官测得比被测者准）、热像仪、环境舱 |
| RIG-002 | 带每轨分流器之测试插槽：逐模块、逐环节测量（基础 04 之硬件化） |
| RIG-003 | **标准化测量报告**：每条 `已验证` 规格引 RIG 报告，含仪器、方法、日期——带仪器的 SDD 第二法 |
| RIG-004 | 台架对接流水线：结果作 CI 制品入库——物理验证成为闸门（EST-004） |

## SEG——法规

| ID | 需求 | 王牌 |
|---|---|---|
| SEG-001 | **调制解调器自我认证**：EXC-001 模块之 ANATEL + FCC + CE——外壳**永不重认证射频**：换调制解调器世代即换已认证模块，非重新审批整机 | 认证化为零件——模块化之结构优势 |
| SEG-002 | 电池：UN 38.3（运输）+ IEC 62133-2（安全）——逐能源模块，同王牌 | |
| SEG-003 | 电气安全 IEC 62368-1 与触温（FRI-003）——外壳 | |
| SEG-004 | RoHS/REACH——材料逐模块卡申报 | |
| SEG-005 | SAR 含于调制解调器模块认证——曝露随件而行 | |
| SEG-006 | 欧盟生态设计（基础 10）：7 年部件、800 循环电池——**自 MOD-002 起即依设计合规** | |

## 边界之读

四领域浮现之模式：**模块化把固定成本化为可换零件**——认证（SEG-001/002）、热预算（FRI-002）、辐射（ANT-002）、乃至测量精度（RIG-001）皆居于可替换而不废其余之处。物理周界服从外壳之法：**快变者是零件；长存者是结构。**
