# 能源链条与链结

**Avatar-Energy · 基础文档 04 · 2026年8月22日**

---

## 链条

**能源链条**是从源头到有效使用之间的转化环节序列。经典模型分三段：

```
一次能源 → 终端能源 → 有用能源
（自然界中   （到达用户     （真正
 的形态）     的形态）        做功）
```

例：井中石油 → 泵站汽油 → 汽车运动。每支箭上皆有损耗。

### 乘法律

链条效率是各环节效率之**积**：

```
η(链) = η₁ × η₂ × … × ηₙ
```

三个推论：
1. **环节互不补偿**——链条之强，止于最弱一环；
2. **短链胜出**——每去一环，总效率相乘而升；
3. **缩短链条即节约**——*节约*操作常以去环行事。

### 链条示例

| 链 | 环节 | 近似 η |
|---|---|---|
| 柴油 → 马达 → 运动 | 开采、精炼、运输、燃烧 | ~20–30% |
| 太阳 → 光伏 → 电池 → 马达 → 运动 | 光电、充、放、牵引 | ~15–20% |
| 太阳 → 光伏 → LED → 光 | 两环直转 | 实用世界最高效之列 |
| 水电 → 电网 → 热泵 → 热 | 重力→旋转→电→泵（COP 3–4） | 会相乘的链：交付 3–4 倍于所耗 |

末行教学：有些环节不止节约——还**放大**（热泵搬运的热多于所耗能源，因其运输而非产生）。

## 链结

**链结**是把一条链的输出——含其残余——接入另一条链的输入：

- **热电联产**：电厂余温暖热城市；
- **产业共生**：一厂之渣为邻厂之料；
- **Power-to-X**：富余电力 → 氢 → 合成燃料 → 运动；
- **热级联**：高温蒸汽供高炉、中温供工业、低温供区域供暖——同一能源逐级用尽。

链结是具体化的*减少浪费*：一环之损化为另一环之食。

## 从链到网

```
链（线性） → 树（分叉） → 图（网络） → 环（闭环）
```

链结的至高阶段是**闭环**：输出回到输入，一无所失——循环经济施于能源。链与链相结成**网**——生态系统之根正以此得名：*Teia*。

## 融入项目体系

- 在**基础 03**，代理的行动空间是**单元格**（操作 × 层级 × 维度——294 格）；
- 每格是一**环**；**链**是穿环之路；**链结**把路连成网；
- 七项操作作用于环；代理——居管理层——**织造**：择路、短链、闭环；
- 在卡尔达肖夫尺度（基础 02），今日行星之网化作明日恒星之网——同图，更大节点。
