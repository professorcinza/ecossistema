# 概念

**Avatar-Energy —— 能源代理**

*架构师定义，2026年8月22日：*

> 本项目的功能是**增效、重定向、分配、节约、储存、配送与减少能源浪费**。

---

## 七项操作

| # | 操作 | 技术含义 |
|---|---|---|
| 1 | **增效** | 提升发电与使用产出：每单位资源获得更多有效能源 |
| 2 | **重定向** | 引导流量：在对的时刻，把能源从过剩处送往短缺处 |
| 3 | **分配** | 按优先级、成本与需求决定去向——包括推迟消费（负荷移峰） |
| 4 | **节约** | 以效率降低消费：用更少做同样的事 |
| 5 | **储存** | 捕获盈余以备后用——电池、氢、重力、热 |
| 6 | **配送** | 经网络送至使用点，中间环节最少 |
| 7 | **减少浪费** | 削减全链损耗：输电、散热、待机消费 |

## 循环

```
发电 → 储存 → 路由 → 分配 → 配送 → 消费
   ↑__________________________________________|
              每一环节的损耗最小化
```

七项操作覆盖完整的能源生命周期——从源头到使用，包括盈余回流。

## 代理

**Avatar**（梵语 *avatāra*，"降临"、化身）：降临于系统并在其中行动的形象。在本项目中，代理是**七项操作的化身**——降临于电网、建筑、身体或数据，并以自身之名管理能源。
