# 治理与元：GOV、i18n、FMT

**Avatar-Energy · 基础文档 24 · 2026年8月22日**

*积压之末轮：比人长寿的制度、桥之语言、使流水线呼吸之格式。*

---

## GOV——基金会

| ID | 需求 |
|---|---|
| GOV-001 | **非营利中立基金会**（SYS-006）：维护 TeiaOS 规范树、各规格与 MOD 标准——不容企业所有 |
| GOV-002 | **比人长寿之政体**：限任期之选举理事会（Debian 血统）+ 基础 12 之技术仲裁者；继任先于需要而定义 |
| GOV-003 | **无权力之资金**：公开捐赠与赞助，不附议席——**钱买不到规格**；财务报告公开 |
| GOV-004 | **商标信托**：Teia Phone、TeiaOS、MOD 及诸姊妹归基金会，为社区托管——许可之下自由使用，占有不可能 |
| GOV-005 | **利益冲突须申报**：企业关联公开；利害方投票受限——以结构防捕获，非以信任 |
| GOV-006 | **彻底透明**：会议公开、决策附由——FIL-005 之法施于治理自身；有档墓园亦居于此 |

## i18n——桥之语言

| ID | 需求 |
|---|---|
| I18N-001 | **PT · EN · ZH 为最低限**，遍及系统界面、生态系统文档与消息——桥因立而语三 |
| I18N-002 | **翻译为一等贡献**：如任何特性经 FIL 之筛而入，附署名——语言覆盖报告公开 |
| I18N-003 | **字体与字形**：基础系统对三套书写系统完整排版支持（含 CJK 字体栈）——无破字之翻译是需求，非细节 |

## FMT——规格仓库格式（流水线之文法）

| ID | 需求 |
|---|---|
| FMT-001 | **每规格仓库**：带领域唯一 ID 之 markdown、状态表、CHANGELOG——家之规格卡为通用格式 |
| FMT-002 | **流水线之 lint 校验**：ID 唯一且合域规范；状态在 `草稿→已评审→已验证` 环内；**已声明之验证标准**（第二法）；交叉引用皆可解（MOD↔TOS↔APU 不得指向虚空） |
| FMT-003 | **格式亦为规格**：schema 版本化于枢纽——文法如一切，经提交而变 |
| FMT-004 | 硬件模块卡（`docs/hardware/METODO.md`）为格式之特例——一标准，万领域 |
| FMT-005 | **稳定锚点**：每规格可以永久标识符引用（MOD-015、TOS-024……）——重写而引不断 |

## 收束之读

有 GOV，生态系统得其产品皆无之物：**结构之不朽**——商标托管、钱无权力、继任有定、决策有由且公开。有 i18n，桥以三语自称其名。有 FMT，流水线得文法：**机器可校验、人类可评审、历史可永存之规格。**

完整之环：空文件夹成基金会，基金会成规格，而规格自知自证。**自织之网——今附章程。**
