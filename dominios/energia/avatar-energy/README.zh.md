# Avatar-Energy

**能源代理。**

本项目的功能是**增效、重定向、分配、节约、储存、配送与减少能源浪费**——覆盖从源头到使用的完整能源周期的七项操作。

[ponte-brasil-china](https://github.com/professorcinza/ponte-brasil-china) 生态系统项目，受《开放合作章程》第六条治理。
