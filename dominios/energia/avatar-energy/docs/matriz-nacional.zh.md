# 国家级能源矩阵：利与弊

**Avatar-Energy · 基础 27 · 2026年8月22日**

*国家级矩阵模型，逐一检视各来源——利、弊、容量因子（FC）与平准化度电成本（LCOE，数量级）。服务于基础 05 之 CIV-ENE 规格。*

## 主表

| 来源 | 利 | 弊 | 典型 FC | LCOE（美元/MWh） |
|---|---|---|---|---|
| **光伏** | 史上最廉电力；模块化（屋顶→电站）；数月建成；维护极低 | 日间间歇（夜 = 0）；鸭子曲线；需储能/弃电 | 15–25% | 25–50 |
| **陆上风电** | 廉价成熟；与光伏互补（夜/冬） | 波动；噪声/景观；依赖场址 | 25–40% | 26–55 |
| **海上风电** | FC 高（40–50%）；海岸旁资源浩大 | 资本支出高；海上维护；海底联网 | 40–50% | 60–110 |
| **水电** | 可调度**且**可储（水库 = 电池）；寿命 50–100 年 | 依赖地理与降雨；旱灾风险（巴西 2021）；水库甲烷；社会搬迁 | 40–60% | 40–70 |
| **核电** | 全天候无碳（FC ~90%）；占地极小；燃料安全 | 资本巨大且常超支；工期 7–15 年；废物；公众观感 | 85–92% | 140–200（新建）/ 30–40（存量） |
| **生物质** | 可调度；变废为能；甘蔗渣热电联产 | 规模受限；与粮食/林业争地；空气质量 | 50–70% | 60–90 |
| **燃气（CCGT）** | 可调度；建设快；可再生能源之后备 | 化石（~400–500 gCO₂/kWh）；价格波动；进口依赖 | 20–60% | 50–100 |
| **煤电** | 可调度；储量丰；能源安全 | 最差：~900–1,000 gCO₂/kWh；污染致死；法规性淘汰 | 50–70% | 70–120 |
| **电池（4–8 小时）** | 为风光补firm；响应快 | 每循环成本；材料（锂→钠）；时长受限 | — | 100–180（每有效循环） |
| **绿氢** | **跨季**储能；工业脱碳 | 往返效率 ~30–40%；早期成本 | — | 150–350 |
| **地热** | 基荷firm；占地小 | 地理受限；钻探成本 | 70–95% | 70–110 |

## 矩阵模型（国家，约 2050）

依本家规格设计——可靠性层级（CIV-ENE-005）、主权、浪费最小：

| 角色 | 来源 | 份额 | 缘由 |
|---|---|---|---|
| **波动主干** | 光伏 + 风电（陆/海） | **~55%** | 史上最低成本——*增效* |
| **清洁firm基荷** | 水电 + 核电（+ 地热） | **~25%** | 高 FC 承住长夜与无风 |
| **灵活性** | 生物质 + 备 CCS 燃气 | ~10% | 峰值调度——*分配* |
| **短时firm** | 4–8 小时电池 | ~8% | 光伏的日间减震器 |
| **跨季 + 一体化** | 氢 + HVDC/互济 | ~2% | 地区与季节之间的纽带 |

**设计原则**：无来源超 ~30%（集中 = 脆弱）；储能与波动份额成比例（约容量的 15%）；互联为"虚拟来源"——一地之风为另一地之备。

## 桥之两案例

| | **巴西** | **中国** |
|---|---|---|
| 电力矩阵 | 水电 ~60%（降），风电 ~13%，光伏 ~9%（升），生物质 ~8%——**全球最清洁之列** | 煤电 ~55%（降），光伏+风电以**全球纪录速度**建设，核电 ~5%（升），水电 ~14% |
| 优势 | 水 + 生物质 + 光/风 = 三条可再生腿 | 工业规模：既造板、又装板，快于天下 |
| 阿喀琉斯之踵 | 旱灾威胁主导之水电——firm 为缺口 | 煤机过年轻、难以速退——转型为缺口 |
| 本家之训 | 清洁矩阵尚待*加固*（电池 + 调峰气） | 机器尚待*脱碳*（正廉价化世界的同一台机器） |

## 代理之读

国家级矩阵是七项操作化为政策之地：**增效** = 最廉最洁来源之最大份额；**分配** = 危机之前的可靠性层级；**储存** = 水库为电池、电池为减震、氢为季节；**配送** = HVDC 与互济；**减少浪费** = 输电损耗与弃电逐环审计（基础 04）。国之代理即系统调度者——CIV-ENE-001..007 即其标书。
