# Inkos Worlds

Sistema de mundos e contratos do ecossistema Inkos — configuração (`inkos.json`) e contratos para construção de narrativas assistida por LLM, com agenda de operações (radar e escrita periódicos) e execução concorrente de obras.

## Estrutura

| Item | Papel |
|---|---|
| `inkos.json` | Configuração do sistema (provedor LLM, agendamentos, limites) |
| `contracts/` | Contratos que definem os mundos |
