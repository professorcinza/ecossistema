## inkos-worlds —— 想象（INK 规格）

**为何物**（测得）：以 **markdown 契约**定义之世界（如 `economia-celula-world`、`gray-protocol-world`）+ 带有 LLM 与自有日程之守护进程配置（周期雷达与写作、并发著作受限）。

| ID | 需求 | 来源 |
|---|---|---|
| INK-001 | **世界即契约**：markdown 文件、人类可读、行于 microSD（MOD-015）、经网（MAL）共享——世界是文件，非应用 | 既有契约 |
| INK-002 | **想象本地运行**：守护进程以 APU 链自身之 LLM（TOS-024）生成叙事——世界写于被读之处 | ECO-005 |
| INK-003 | **写作服从能源**：守护进程订阅代理之接口，唯能源可用方写（*分配*操作施于想象——系统之笔记永不吸干要务之电） | 架构师 |
| INK-004 | **契约即规格**（SDD 天生）：参考实现待软件卡开启时入流水线；既有契约为首批活规格 | SDD |
| INK-005 | 世界采 CC BY-SA、可审计、版本化——带监管链的想象 | 家规 |

## Our-Civilization-The-Game —— 训练（CIVG 规格）

**为何物**（BLUEPRINT 与 openspec 中测得）：**本地优先、事件溯源、LLM 叙事**之 RPG 引擎——四级水晶记忆、NPC 私有心智、屏外世界滴答、事后审计者；无 HP、无刷怪。设计即双语 en+pt-br。MMO 为引擎之上层。**openspec 中 22 项能力成规格、蓝图一对一可溯源——游戏先于规范实践了本家 SDD。**

| ID | 需求 | 来源 |
|---|---|---|
| CIVG-001 | **被采纳为 SDD 规范之活证据**——游戏之 openspec↔蓝图对为可引用之范例 | 规范 I |
| CIVG-002 | **引擎运行于 Teia Phone**：本地优先 + 本地 LLM（TOS-024）——训练发生于士兵/学生所在之处，无需网络 | ECO-006 |
| CIVG-003 | **zh 成为内容第三语言**（已有 en+pt-br）——桥之所求：如枢纽般三语剧本。生态系统对游戏之贡献，待架构师决 | 桥 |
| CIVG-004 | **MMO 层运行于 MAL 网之上**——存在、社会与规模皆 P2P：邻里可玩之多人游戏，无中央服务器 | MAL |
| CIVG-005 | **CIV 规格之官方模拟器**（基础 05）：文明现象于引擎中演练，TEIA 卷宗喂养剧本，反之亦然 | 基础 05 + KER-003 |
| CIVG-006 | 每项贡献保留 DCO 签核——游戏已要求；本家采纳 | 游戏政策 |

## 完整地图之读

五项集成成规格，基础 17 之会聚闭合成环：**心智**（kernel）产出分析；**警戒**（poder-visivel）发布；**网**（MAL）分发；**想象**（inkos）叙事；**训练**（civilization）演练——皆载于 MOD 底盘、受 TeiaOS 规范系统治理、由 APU 链供能。而系项目于其名之一笔：连想象（INK-003）也在耗电前先请示代理。**整个生态系统以七项操作呼吸。**
