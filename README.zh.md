## 关于本项目

本项目致力于在巴西与中国两国人民之间架设持久的友谊、理解与互利之桥。我们相信，建立在**共同协议**、**公开透明**与**相互尊重**基础上的关系，能为双方创造持久的价值。

本项目以一项**单方面承诺**起步——而非一场谈判——由一个人在不持有任何代表权的情况下承担，追求一种以相互支持与互助为基础的双边合作局面。

## 原则

1. **共同协议** — 一切合作均源于所有相关方的自由、知情同意。
2. **互利共赢** — 只让一方受益的提案不是好提案。
3. **公开透明** — 本仓库内容公开、开放。
4. **遵守法律** — 遵守巴西法律、中国法律及适用的国际条约。
5. **非官方性质** — 本项目为公民个人项目，与任何政府无关。
