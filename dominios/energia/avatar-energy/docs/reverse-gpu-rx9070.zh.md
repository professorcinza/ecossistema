## 制品

**Radeon RX 9070**——Navi 48、RDNA 4，2025 年 3 月发布，2026 年 8 月街价约 549 美元。

## 硅片（测得/官方）

| 项 | 值 |
|---|---|
| 制程 | 台积电 N4P（4 nm） |
| 计算单元 | 56 CU · 3,584 着色器 |
| 游戏/加速频率 | ~2.1 GHz / ~2.7 GHz |
| **FP32** | **~36.1 TFLOPS** |
| 显存 | 16 GB GDDR6 · 256 位 · 20 Gbps → **640 GB/s** |
| 无限缓存 | 64 MB |
| 整板功耗（TBP） | **220 W** |
| 待机 | ~7–15 W |
| 接口 | PCIe 5.0 ×16 |
| 加速器 | 第三代 RT · 每 CU 之 AI（WMMA） |

## 选出之账

- **~164 GFLOPS/W FP32**——开放栈之最佳能效；
- 1440p 约 0.83 FPS/美元——虽对更廉之卡仍居性价比之首；
- 16 GB 显存、640 GB/s：本地 ~13B 大模型从容，量化 ~30B 可跑。

## 何为开放——诚实之残余

| 层 | 状态 |
|---|---|
| 内核（amdgpu） | 主线，首日 |
| Mesa（RADV/RadeonSI） | 主线，首日——测试游戏中 Linux 比肩/超越 Windows |
| 计算（ROCm） | RDNA4 支持渐熟 |
| **固件** | **残余**：可再分发之 blob，非源码——栈中唯一非开放部分 |

## 坞 GPU 模块规格（导出；后为 APU v4 取代）

GPU-001：电 envelope ≤ 220 W · GPU-002：坞内原生 PCIe · GPU-003：显存 ≥ 16 GB、带宽 ≥ 600 GB/s · GPU-004：待机纪律 ≤ 10 W · GPU-005：**主线驱动强制——首日** · GPU-006：可再分发固件为底线、开放优先 · GPU-007：视频输出于坞板。

## 能耗之读

基准授三课：**峰值与待机为两世界**（220 W 对 <15 W——*分配*操作居其间）；**内存为机器之半**（故定带宽底线，非仅容量）；**固件残余标示开放前线之所在**——插槽恰为此不可知论：待连此残余亦为源码之日。
