# MOD 网状网节点：网之物理基础设施

**Avatar-Energy · 基础 32 · 2026年8月22日**

*Teia Phone 之外首个 MOD 系列产品。网状网节点将 MAL 规格（基础 18）物质化：每个节点延伸整个生态系统赖以呼吸的离线优先之网。架构：十年外壳，轮换模块，光能自供。*

---

## 模型：四模块，一外壳

```
[IP67/MIL-810 外壳 — 10+ 年]
  ├── 射频模块（5–8 年）   — Wi-Fi 6/7 + BLE 5.x + LoRa
  ├── 能源模块（5–8 年）   — 柔性 OPV + 钠离子电池
  ├── 算力模块（4–6 年）   — RISC-V，ISA 无关插槽
  └── 天线（外壳寿命）     — ANT-001：天线在外壳，永不在模块
```

## 代理之读

网状网节点是**重定向操作化为硬件**：不产信息、不耗内容——**转发**。每节点是网物理存在所需的链条一环（基础 04）。因每节点自供能（MN-009/011），基础设施之能耗为**零**：日光与灯光为网买单。

**统一化**：网状网节点用同一存储（MOD-015）、同一算力插槽（D1）、同标准电池（MOD-002）、同一系统（TeiaOS）、同一协议（MAL）、同一代理。**它是无屏的 Teia Phone，天线更大。**规模经济是真实的：一插槽，两产品。
